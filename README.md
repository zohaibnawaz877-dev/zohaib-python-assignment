# Task Tracker Mini Project

## Project Goal
A Python-based command-line Task Tracker application designed to manage daily tasks. It allows users to add, view, complete, and delete tasks with automatic JSON storage persistence.

## Features
- Add tasks with custom titles (default status: Pending).
- View all tasks with their current status (Pending / Done).
- Mark specific tasks as completed.
- Delete tasks from the list.
- Save and load tasks automatically using `tasks.json`.
- Input validation and basic error handling for empty titles and invalid choices.

## How to Run
1. Open Google Colab or any local Python environment.
2. Download or copy `mini_task_tracker.py`.
3. Run the script using Python:
   ```bash
   python mini_task_tracker.py
